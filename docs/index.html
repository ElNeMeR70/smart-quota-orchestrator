❓ Engineering & Security FAQ

    

      

        

          1. Does SQO upload my source code anywhere?
          
Never. 100% of the 53 MCP tools, hook shields, SAST, FinOps, and SQLite databases (.sqo/) run offline on your local machine using Python's built-in standard library.

        

        

          2. Why Zero External pip Dependencies?
          
Zero pip install means zero broken virtualenvs, zero supply-chain attack surface, instant startup (<15ms), 0.0% idle CPU, and effortless portability across Windows, macOS, Linux & CI!

        

        

          3. Does it protect the 90% Prompt KV-Cache discount?
          
Yes — 100%. Unlike naive plugins that inject timestamps on every turn (invalidating Anthropic/Gemini/OpenAI prompt caches), SQO injects static memories at SessionStart only and audits prefix stability via sqo cache-audit.

        

        

          4. Which command should I run first on an existing repo?
          
Run npx -y smart-quota-orchestrator init -w . once to bootstrap shields, then use sqo autopilot "your task" before coding and sqo pr-shield before committing!
