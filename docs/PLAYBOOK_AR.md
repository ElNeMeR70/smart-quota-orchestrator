### 💬 الحوار الثاني: فخ إعادة قراءة نفس الملف وملفات القفل العملاقة (`package-lock.json`)
> **رسالة المبرمج:** *"راجع تعارض الحزم وعدّل إعدادات المصادقة في ملف `monolith_controller.ts` (طوله 2,400 سطر)."*

- **ماذا يحدث خلف الكواليس في أقل من `12ms`؟**
  1. يحاول الوكيل تنفيذ `read_file("package-lock.json")` (`420 KB`):
     🛡️ يتدخل **حاجز قنابل التوكنز (`Token-Bomb Blocker`)** فوراً ويرفض العملية قبل إرسالها للنموذج، موجّهاً الوكيل لقراءة `package.json` فقط -> **توفير `107,000` توكن وتوثيقها في `sqo roi`!**
  2. يطلب الوكيل `read_file("monolith_controller.ts")` بدون تحديد أسطر:
     ✂️ يتدخل **المُقلّم التلقائي (`Giant-File Auto-Clamper`)** ويعدّل الطلب في الهواء (`overwrite`) ليقرأ `StartLine: 1, EndLine: 280` فقط -> **توفير `19,500` توكن!**
  3. بعد 4 رسائل، ينسى الوكيل ويحاول قراءة نفس الملف `monolith_controller.ts` مرة ثانية رغم عدم تعديله:
     🚫 يتدخل **مانع التكرار الذكي (`Stateful Deduplicator`)** ويقول له: *"لقد قرأت هذا الملف في الخطوة #3 ولم يتغير على القرص؛ استخدم النسخة الموجودة في ذاكرتك!"* -> **توفير 100% من القراءات المكررة!**
  4. ما إن يعدّل الوكيل الملف بـ `edit_file`، يفتح `PostToolUse` القفل تلقائياً ليسمح بقراءة التعديلات الجديدة بسلاسة!

## 🛠️ الجزء الثاني: وصفات عملية جاهزة لكل مطور

### 1. لمطوري مشاريع الـ SaaS والمواقع الكاملة
نفّذ هذه الأوامر الثلاثة مرة واحدة في أي مشروع جديد:
```bash
# 1. ربط خادم الـ MCP وملفات الحماية تلقائياً في جميع محررات الذكاء الاصطناعي الخمسة
python sqo.py sync-ide --workspace . --ides all

# 2. تثبيت حارس Git قبل الـ Commit لمنع تسريب المفاتيح السرية وتضخم القواعد
python sqo.py git-guard --workspace .

# 3. استخراج جدول كل مسارات الـ API والشاشات في أقل من ثانية
python sqo.py routes --workspace .
```

### 2. لمطوري تطبيقات الموبايل (Flutter / Android / iOS) والواجهات
مشاريع الموبايل تمتلئ بصور التصميم عالية الدقة (`4K PNG`) وملفات `pubspec.lock`:
```bash
# احسب تكلفة الصور وملفات الـ PDF بالتوكنز قبل إرفاقها في المحادثة!
python sqo.py media --workspace assets/

# اكتشف أعقد ملفات الكود وأكثرها عرضة للأخطاء (Hotspots)
python sqo.py hotspots --workspace lib/
```

### 3. متابعة التوفير المالي الفعلي بالدولار والتوكنز (`ROI Ledger`)
في أي وقت، اعرف كم وفّرت المنظومة لك تلقائياً:
```bash
python sqo.py roi
python sqo.py doctor --workspace .
```
